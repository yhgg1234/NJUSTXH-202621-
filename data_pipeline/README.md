# Data Pipeline

该目录用于存放与数据流程相关的代码和脚本，包括但不限于：

- 数据采集与爬虫
- 原始数据清洗
- 数据去重
- 字段标准化与映射
- Excel 模板整理
- JSON / Excel 等格式导出

当前不强制划分更细的子目录。后续数据同学可以根据自己的实现方式，在本目录下自行组织脚本、模块或配置文件。

注意：大规模真实数据不要放在本目录提交到 Git。数据文件优先放入 `data/raw/` 或 `data/processed/`，并遵守仓库 `.gitignore` 规则。
